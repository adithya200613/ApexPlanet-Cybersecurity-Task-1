# Cryptography and OpenSSL Notes

- **Plaintext:** Original readable information.
- **Ciphertext:** Information transformed by encryption.
- **Encryption:** Converts plaintext into ciphertext.
- **Decryption:** Restores ciphertext using the required key.
- **Symmetric cryptography:** Uses the same secret key for encryption and decryption.
- **Asymmetric cryptography:** Uses a public/private key pair.
- **Hashing:** Produces a fixed-length digest; it is not reversible encryption.
- **Digital signature:** Helps verify authenticity and integrity.
- **TLS certificate:** Binds an identity to a public key for authenticated TLS.

OpenSSL is a toolkit for cryptographic operations and certificate handling.
